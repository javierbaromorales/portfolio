# Javier Baro Morales

Cinematic personal site. Architecture is the visual language — layers, hairline grids, and type, not orbs or a 3D sphere.

## Stack

- Next.js 16 App Router, React 19, TypeScript
- Tailwind CSS v4 with a custom token set
- GSAP 3.12+ + `@gsap/react` + Lenis 1.x (`lenis/react`)
- Selective shadcn (Sheet, Button) on Base UI

## Commands

```bash
pnpm dev
pnpm lint
pnpm tsc --noEmit
pnpm build
```

Content lives in `src/content/`. Replace placeholders (email, GitHub, project writeups, role sentences) before shipping.
